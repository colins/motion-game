I want to design an activity for 8-10 year old kids using touchdesigner https://derivative.ca/UserGuide/Getting_Started_With_TouchDesigner
It should be an active game that lets kids run around chasing and capturing virtual beasts.
It should be a floor game
I am a software engineer but have no experience using TouchDesigner
